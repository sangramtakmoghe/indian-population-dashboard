# India Population Explorer | Tableau Dashboard

An interactive dashboard exploring India's population using demographic estimates from the United Nations *World Population Prospects 2024*.

## Project Overview

**India Population Explorer** is a data visualization project designed to explore India's population structure using population estimates for 2025. The dashboard aims to make demographic information easier to understand through interactive visual analysis.

The project demonstrates practical skills in data preparation, demographic analysis, and dashboard development using Microsoft Excel and Tableau.

> **Data note:** The 2025 figures are population estimates, not results from a new Indian population census.

## Objectives 

- Explore India's estimated population distribution by age and sex.
- Compare male and female population figures.
- Understand India's demographic structure through visualizations.
- Present population data in an accessible, interactive dashboard.

## Tools and Technologies

- **Tableau** — dashboard development and data visualization.
- **Microsoft Excel** — data cleaning, preparation, and validation.
- **UN World Population Prospects 2024** — demographic data source.
- **GitHub** — project documentation and version-controlled portfolio.

  ## Data Source

  The project uses population data from the United Nations Department of Economic and Social Affairs, Population Division.

- **Dataset:** World Population prospects 2024
- **Geographic coverage:** India
- **Reference year:** 2025
- **Reference date:** 1 July 2025, where applicable to the selected WPP estimate
- **Official website:** https://population.un.org/wpp/

  The figures represent United Nations demographic estimates and projections. They should not be interpreted as a direct enumeration from a census conducted in 2025.

  For additional information about the source and methodology, see [`docs/data_source.md`](docs/data_source.md).

## Data Preparation 

The population dataset was prepared in Microsoft Excel being used in Tableau.

The preparation process focused on:

- Selecting the relevant India population records for the reference year.
- Retaining the demographic fields required for analysis.
- Checking data types, missing values, and age-group consistency.
- Reviewing population categories and sex classifications.
- Validating figures for consistency before visualization.

The exact transformations depend on the source file and the final dataset included in this repository.

## Dashboard Features

The project focuses on exploring population structure through demographic analysis, including:

- **Population overview:** examination of India's estimated population.
- **Age distribution:** exploration of population across age groups or individual ages.
- **Sex distribution:** comparison of male and female population figures.
- **Demographic structure:** visual exploration of how population is distributed across age and sex categories.

Refer to the published dashboard or the included Tableau workbook to explore the actual visualizations and interactive features.
